Шаг 1. Ваш API-ключ

Скопируйте этот ключ — он понадобится при первом запуске приложения.

Никому не показывайте этот ключ — тот, у кого он есть, получит доступ ко всем данным вашего аккаунта.

Шаг 2. Скачайте приложение

Скачайте архив с приложением на планшет и распакуйте его в удобную папку (например, D:\FoodSafe\).

Скачать FoodSafe {{ app_version }}

Не распаковывайте в C:\Program Files\ — Windows может запретить запись данных.

Шаг 3. Запустите приложение и введите ключ
  1. Распакуйте архив.
  2. Откройте папку FoodSafe.
  3. Дважды кликните FoodSafe.exe. Антивирус Windows может ругаться при первом запуске, нажимаем "Подробнее" и "Выполнить в любом случае". Программа без вирусов
  4. В поле «API-ключ» вставьте ключ из шага 1.
  5. Нажмите «Подключиться и синхронизировать».

После синхронизации приложение работает оффлайн — интернет нужен только при нажатии кнопки «Синхронизация».

Шаг 4. Настройте принтер, если еще не настроили
  1. Установите драйвер AiYin IP802, ссылка внизу страницы
  2. В «Устройства и принтеры» создайте размер бумаги 58 × 60 мм
  3. В приложении нажмите ⚙ Настройки → выберите принтер → сохраните.
  4. Попробуйте напечатать одну маркировку и корзину. Если принтер пропускает этикетки — увеличьте «Пауза между этикетками» в настройках приложения.
